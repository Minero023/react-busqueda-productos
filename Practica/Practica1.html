1. Textos, Enlaces y Cajas Flexibles

En HTML podemos dar formato semántico al texto usando negritas de importancia (strong), texto enfatizado en cursiva (em), o aplicar estilos específicos con CSS usando un elemento span con clase sin romper la línea del párrafo.

2. Estructura de una Tabla

Las tablas se dividen semánticamente en cabecera (thead) y cuerpo (tbody).

Etiqueta / Propiedad Lenguaje Función Principal
display: flex; CSS Organiza elementos en filas o columnas fácilmente.
margin / padding CSS Controla el espacio exterior (margin) e interior (padding).
<section> / <div> HTML Contenedores de bloque para agrupar contenido.
